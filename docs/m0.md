# M0 smoke sequence

Deterministic Soft script `soft/arena/m0_smoke.aura`. Seed `20261005`,
horizon 48. Dialect string: `live-rules-arena-m0`.

One ball in a 64×48 box. Two rule packs. The numbers are the race.

## Law

1. Seed step: `(modulo (+ (* seed 75) 74) 65537)`. This seed steps to
   `34567`, so the shared start is `x=16 y=36 vx=3 vy=2`.
2. Each tick subtracts `g` from `vy`, then adds velocity to position.
3. `x` outside `[0, 64]` clamps and replaces `vx` with
   `-qdiv(vx * bn, bd)`. `y` above 48 does the same for `vy`.
4. `y` below 0 clamps to 0, bounces `vy` the same way, then pulls `vx`
   toward 0 by `fric` (integer, no sign flip past 0).
5. `qdiv` is toward-zero quotient.
6. `ke = vx*vx + vy*vy` after contact. `y=0` and `ke=0` is stuck. That
   frame is not committed and does not increment `alive`.
7. Score is `(+ (* alive 1000000) energy)` where `energy` is the sum of
   `ke` over in-play ticks. `energy` on this horizon stays below 1000000,
   so `quotient(score, 1000000)` is `alive`.

| 1 | `rules-heavy` | 4 | 1/3 | 2 |
| 2 | `rules-light` | 1 | 2/3 | 1 |

Heavy falls, sticks, and dies at tick 9 (8 ticks in play). Light keeps
bouncing until tick 36 (35 ticks in play). Neither body calls `set-code`.
M0 does not `hot-strategy:register!` them.

## Race

Same seed, both packs. The race thunks only return a score. They do not
`set!` the main slot, so a real fiber cannot publish the loser's ball
into the live world.

`fiber:spawn` both thunks, then `fiber:join`. `fiber_live` only when the
ids are distinct and positive, both joins are numbers, `joins` equals
`spawned`, and `fiber:spawn-backend` is `> 0`. Otherwise the thunks run
on the host and the stamp is `host-sequential`.

The greater score wins. A survival tie would break on energy. A full tie
would KEEP heavy (`tie-keep-heavy-stamp`). This seed is not a tie.

The winner is replayed with the tape flag on. The loser is not replayed.
That is the rollback.
